
# OOP Chess Game in C++

## Project Description
This is a semester OOP project implemented in C++. The project simulates a chess game using object-oriented programming concepts such as inheritance, polymorphism, and abstraction.

## Features
- 8x8 chess board representation
- Multiple chess pieces (Pawn, Rook, Knight, Bishop, Queen, King)
- Each piece has its own movement rules
- Turn-based gameplay (White & Black)
- Move validation using polymorphism
- Capture system implemented
- Dynamic memory management

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism (virtual functions)
- Abstraction
- Dynamic memory allocation

## How to Run
1. Compile all .cpp files using a C++ compiler (g++)
2. Run the executable file
3. Follow console instructions to play the game
